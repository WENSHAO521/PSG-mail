# 界面检查与易用性修复

方法：用本地 Worker + 本地 D1（`wrangler dev --local`，按真实顺序先 `/api/init` 再应用全部 19 个迁移）跑起完整应用，用 Chromium 在桌面（1366px）、手机（390px）、浅色/深色下逐页操作并截图，同时监听控制台错误、失败请求和横向溢出。检查范围：登录、收件箱、阅读、写信、个人设置、设备管理、改密码、系统设置（含数据治理）、AI 助手抽屉及其设置/草稿。**没有检查**：Electron、Android 原生壳、定时发送、云备份、通知推送。

检查过的页面里没有 JS 报错、没有失败的接口请求、没有横向滚动。

## 发现并修复
| 问题 | 原因 | 修复 |
|---|---|---|
| 列表预览把段落粘在一起（`Dear editor,please`） | 用 `textContent` 取 HTML 文本，块级标签之间没有空白 | 提取前在块级边界补空格 |
| 新装系统弹出“Cloud Mail 仅供学习交流”公告；管理员清空后每次部署又被恢复 | `init.js` 每次 `/init` 都把空公告写回上游默认文字 | 不再写入；空公告不弹窗。**已有部署里已经存在的公告不会被自动清除**，需管理员在 系统设置 → 网站公告 里清空 |
| 公告压在顶栏上，挡住「发邮件」和账号菜单 | 默认偏移为 0 | 顶部公告至少避开顶栏 |
| 登录/注册只能填邮箱前缀，粘贴完整地址报“邮箱不合法” | 总是追加域名后缀 | 已含 `@` 的地址按原样使用 |
| 设备列表显示 `Linuxundefined`（也写进了用户表的 `os` 字段） | 拼接系统版本时未判空 | 判空；已存的旧字符串不改 |
| 手机上改密码/设备对话框顶部被页头遮住 | 对话框渲染在带层叠上下文的容器内 | `append-to-body` |
| 每个发件人的邮箱 MD5 被发给 gravatar.com | 头像默认走 Gravatar | 默认关闭；构建时设 `VITE_GRAVATAR=true` 才启用（改用首字母/上传头像） |
| 数据治理：工作日选择器渲染成竖排长条；预览警告是英文开发者文本且为红色 | 样式缺失、直接显示后端字符串 | 横排标签；后端返回结构化代码，前端翻译成人话，改用中性色 |
| AI 草稿只能复制 | — | 新增「在写信窗口打开」：带收件人、主题、线程信息和原文引用，由用户检查后自己发送 |

## 已知但未处理
- 头像菜单里的「PSG Connect」(VPN) 和「客户端下载」页对内部邮箱可能不需要，是否隐藏由你决定。
- 已有部署里已保存的旧公告仍会显示（见上）。
- 全新数据库必须先 `POST /api/init` 再应用 D1 迁移（0005、0007 等会给 `email` 表建索引）。这是原有顺序，不是本次引入；若部署流程先跑迁移，全新库会失败。
- 调试时 `wrangler dev` 在热重载时自身崩溃过一次（工具问题，重启后正常），与应用无关。
